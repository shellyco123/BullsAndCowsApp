# Bulls and Cows

- `Console`: the command-line game (Phase 1). Open `Console/BullsAndCowsApp.slnx`.
- `Maui`: the one-page .NET MAUI app that uses MVVM (Phase 2). Open `Maui/BullsAndCowsApp.slnx`, choose Windows Machine and press F5.

Both use the same Model classes. Requires Visual Studio 2026 and .NET 10.
